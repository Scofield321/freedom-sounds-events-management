# Freedom Sounds & Events Management

A modern web application for a **Music Instruments Store** and **Events Management System**, built with a mobile-first approach for seamless shopping and event organization.

---

## 🎵 Overview

**Freedom Sounds & Events Management** is an online platform that allows users to:

- Browse and purchase **musical instruments**
- View product details and search in real time
- Manage events, bookings, and related services
- Enjoy an optimized experience across all devices  
  (Mobile-first responsive layout)

The system includes a beautiful UI, product filtering, search analytics, banner management, and admin dashboard tools for managing store content.

---

## ✨ Features

### 🛍️ Music Instruments Store

- Product listing grid (mobile-first)
- Product detail pages
- Real-time search with partial word matching
- Search tracking (counting most searched items)
- Responsive product cards
- Category browsing
- Image display optimization

### 🎉 Events Management System

- Event listings
- Event details pages
- Booking or inquiry functionality
- Upcoming events section
- Admin tools for managing events

### 🛠️ Admin Dashboard

- Add/Edit/Delete products
- Banner management
- Event management
- Search statistics graph (Chart.js)
- Real-time product search analytics
- Responsive layouts for mobile + desktop
